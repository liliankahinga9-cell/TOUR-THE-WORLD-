# 🌍 Tour The World - Karibu Agent

**Dual Track Entry: Bifrost by Maxim AI + Tavily**

Built live from Eldoret, Kenya - Making Kenya travel accessible with real-time data and cost-optimized AI.

### 🚀 What it does
User asks: "2-day budget tour from All over the world to see flamingos in Dollars" → App gives day plan with live 2026 costs + verified sources.

### Track 1: Bifrost by Maxim AI (Why I used it)
- **Smart Routing:** short query -> gpt-4o-mini (cheap), complex query -> gpt-4o (smart) = 70% cost saving
- **Observability:** Maxim dashboard shows latency, cost, tokens
- **No vendor lock:** One API for all models via https://api.getmaxim.ai/bifrost/v1

### Track 2: Tavily (Why I used it)
- **Live Search:** No hallucinations - searches 2026 park fees, Land cruiser costs
- **Sources:** Returns URLs + citations for trust
- **Real-time:** Always up-to-date Kenya travel data
